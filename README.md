# EnglishGo

Офлайн-приложение в браузере для изучения разговорного английского. Интерфейс на русском, материал на английском с русскими пояснениями.

Работает без интернета, без сервера и без установки: достаточно открыть `index.html`. Никаких внешних библиотек, шрифтов, CDN и API. Прогресс хранится локально в IndexedDB браузера.

## Быстрый старт

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере (Chrome, Edge, Firefox, Safari) двойным кликом или перетаскиванием файла в окно.

Сборка, менеджер пакетов и локальный сервер не нужны.

## Возможности

- **Учить сегодня.** Ежедневная сессия: новые фразы вашего уровня плюс повторение тех, что пора повторить.
- **Уроки.** 70 уроков по темам (знакомство, кафе, магазин, работа и другие) на уровнях A1–C1.
- **Интервальное повторение (SRS).** Каждая фраза возвращается к вам тогда, когда вы начинаете её забывать.
- **Упражнения.** Карточки, выбор значения, фраза в контексте, ввод по памяти, аудирование и диктант, реакция на реплику на время, сборка фразы из слов, выбор стиля речи, перевод между обычной, сленговой и «мессенджерной» формой.
- **Разговор.** Сценарии, в которых вы сами пишете ответы. Приложение понимает свободный текст, сокращения и разговорные формы (`gonna`, `I'm`, `idk`, `r u`) и оценивает, насколько естественно прозвучал ответ.
- **Диалоги.** Ветвящиеся диалоги с выбором реплики: лучший вариант, допустимый, неловкий или неверный.
- **Чаты.** Эмулятор мессенджера с 7 собеседниками и 14 эпизодами. У каждого собеседника свой стиль общения: с другом можно писать сленгом, с арендодателем нужно полными словами.
- **Истории.** 14 коротких текстов для чтения с вопросами на понимание.
- **Игры.** «Сленг-пары», «Расшифруй чат», «Молния», «Ответь в чат», «Собери фразу», «Правда или нет». В каждой есть жизни, комбо и рекорды, а одна из игр каждый день становится «Игрой дня» с двойным XP.
- **Ошибки.** Все ошибки собираются в одном месте, и их можно отдельно потренировать.
- **Прогресс.** Опыт (XP), серия дней, дневная цель, статистика и графики.
- **Адаптивность.** Сложность новых фраз и таймеры подстраиваются под то, как вы отвечаете.
- **Озвучка.** Используется встроенный синтез речи браузера. Если английского голоса в системе нет, аудио-упражнения просто не предлагаются.
- **Резервная копия.** В настройках можно выгрузить прогресс в JSON-файл и загрузить его обратно (с возможностью отменить импорт).

Словарь насчитывает 347 фраз уровней A1–C1, для 236 из них указаны сленговые и мессенджерные варианты.

## Данные и приватность

- Весь прогресс хранится только в вашем браузере (IndexedDB). Ничего никуда не отправляется: политика CSP в `index.html` запрещает любые сетевые запросы.
- Если очистить данные сайта в браузере, прогресс пропадёт, поэтому время от времени делайте резервную копию в «Настройках».
- Если браузер не даёт открыть IndexedDB, приложение продолжит работать, но прогресс не сохранится после закрытия. В этом случае появится предупреждение.
- Одновременно данные может менять только одна вкладка. Если приложение уже открыто в другой вкладке, вам предложат продолжить работу в текущей.

## Разработка

Проект написан на чистых HTML, CSS и JavaScript. Основные ограничения:

- **Без ES-модулей.** Chrome не загружает `type="module"` по `file://`, поэтому каждый файл — это обычный скрипт в IIFE, который добавляет свои функции в глобальное пространство `window.EG`. Зависимости задаются порядком `<script>` в `index.html`, новые файлы нужно добавлять туда в правильное место.
- **Без внешних зависимостей и сети.**
- **Строгая CSP.** Запрещены inline-скрипты, атрибуты `style="..."` и `innerHTML` с данными.

Проверки после изменений:

```sh
# синтаксис
for f in js/*.js js/views/*.js data/*.js; do node --check "$f"; done

# контент и логика: примеры, ссылки, достижимость узлов чатов, оценка ответов, генераторы игр
node tools/check.js
```

`tools/check.js` при успехе выводит `OK`, а при ошибках перечисляет их и завершается с кодом 1. Запускайте его после любого изменения контента.

Подробное описание архитектуры и правил оформления контента есть в [CLAUDE.md](CLAUDE.md).

### Как добавить фразу

Добавьте строку в `data/vocabulary.js`:

```js
V(level, type, register, en, ru, example, exampleRu, usage, { cue, cueRu, alt })
```

- `example` должен содержать фразу `en` дословно, иначе не получится сгенерировать упражнения на контекст.
- `cue` — реплика, на которую отвечает эта фраза. С ней фраза попадает в упражнение «реакция».
- `alt` — допустимые альтернативные ответы.
- Идентификатор фразы строится из английского текста. Если вы меняете `en` у существующей фразы, добавьте `'старый-id': 'новый-id'` в `D.idAliases`, чтобы не потерялся прогресс пользователей.

Уроки собираются из словаря автоматически, по теме и уровню.
